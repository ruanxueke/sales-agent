> 日期：2026-09-11
> 目标：把本地已经验证的客户消息接待链路同步到现有云服务器

## 一、这次需要同步的内容

### 后端

- `api_server.py`
- `api/personal_wechat.py`
- `core/personal_wechat.py`
- `core/models.py`
- `core/commercial.py`
- `core/db.py`
- `core/llm_router.py`

### 前端

- `static/console.html`

`渠道接入 → 客户接待链路`

### 本机桥接

- `wechat_bridge/`
- `start_cloud_auto_reply.bat`

本机桥接不部署到云服务器，在 Windows 微信电脑上运行。

## 二、服务器部署

1. 上传 `release/personal-wechat-cloud-20260911.zip` 到服务器。
2. 解压到：

```bash
mkdir -p /opt/sales-agent/releases
unzip -o personal-wechat-cloud-20260911.zip \
  -d /opt/sales-agent/releases/personal-wechat-flow-20260911
```

3. 使用解压包自带的部署脚本执行安装：

```bash
bash /opt/sales-agent/releases/personal-wechat-flow-20260911/deploy/install_personal_wechat_flow_20260911.sh \
  /opt/sales-agent/releases/personal-wechat-flow-20260911
```

脚本会：

- 备份旧文件。
- 覆盖后端和前端。
- 重建并启动 Docker 容器。
- 检查 `/health`。
- 检查 `/api/v1/personal-wechat/status`。
- 检查前端是否包含“客户接待链路”。

## 三、云端验证

```bash
BASE_URL=https://your-domain.example \
API_KEY=你的APIKey \
bash /opt/sales-agent/deploy/verify_personal_wechat_flow_20260911.sh
```

## 四、本机连接云端

云端部署完成后，在 Windows 电脑运行：

```text
start_cloud_auto_reply.bat
```

对应配置：

`wechat_bridge/config.cloud-test.json`

它会：

- 连接 `https://your-domain.example`。
- 读取本机微信消息。
- 将昵称与消息同步到云端。
- 领取云端生成的回复任务。
- 在微信电脑端自动发送。
- 回读数据库确认发送结果。

## 五、验证顺序

1. 打开 `https://your-domain.example/static/console.html`。
2. 登录中台。
3. 进入“渠道接入 → 客户接待链路”。
4. 启动本机 `start_cloud_auto_reply.bat`。
5. 页面中的“本机桥接”应在 90 秒内显示在线。
6. 用客户微信发送一条新消息。
7. 页面应出现新的消息与回复任务。
8. 微信端应收到自动回复。
9. 任务状态应变为 `sent`。

## 六、当前不包含

- 自动同意好友申请。
- 群聊自动回复。
- 视觉执行器前端入口。
